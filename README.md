# 🧮 Age Group Teller (Python + Pygame)

This is a simple Python GUI application built using **Pygame** that calculates a person's **age** and categorizes them into an **age group** based on their date of birth.

## 🚀 Features

- Interactive GUI to input Date of Birth (DOB)
- Validates input format (DD-MM-YYYY)
- Calculates exact age in years
- Categorizes users into age groups:
  - Infant
  - Child
  - Pre-Teen
  - Teenager
  - Young Adult
  - Adult
  - Middle-aged
  - Senior

## 🛠 Technologies Used

- Python 3
- Pygame
- Datetime module
